# Flyer & Partner

Source data: partner/partner.json. Add a partner with name, website and description.de/en/bs. Optional code displays a public code; leave it out when codes are distributed by partners. Set active:false to hide a partner. Never invent codes.

Run npm run site:build, then npm run site:check. Generated pages: partner/index.html, partner/en.html, partner/bs.html. Footer links and sitemap are included. The 3D flyer loads on demand from /flyer/.

Partner descriptions verified on 17 September 2026 against the website linked in each record. Cooperation and the 10% benefit on all sessions/packages were confirmed by the website owner. No logos or third-party embeds are loaded.
